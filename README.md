# Учебный проект по Python

## В данном проекте реализованы функции маскировки номера банковского счета, генерации и маскировки номера карты, а также сортировка банковских операций по дате, валюте, состоянию и типу транзакии

### **Инструкция по установке:**

1. Клонируйте проект используя команду:

```
git clone git@github.com:vajskerberv/project.git
```

2. Инициализируйте виртуальное окружение:

```
python -m venv <название_окружения>
```

3. Активируйте окружение:

- macOS и Linux:

```
source venv/bin/activate
```

- Windows:

```
venv\Scripts\activate
```

4. Установите зависимости, указанные в `requirements.txt`:
```
pip install -r requirements.txt
```

- Функция `card_number_generator`

Принимает начальное и конечное значение генерации от 1 до 9999999999999999 и поочерёдно возвращает
сгенерированный номер в формате XXXX XXXX XXXX XXXX

        Пример 

      Ввод: начальное значение - 36, конечное значение - 174

      Вывод: 0000 0000 0000 0036

      При последующих вызовах функции возвращается число, увеличенное на 1
      (0000 0000 0000 0037, 0000 0000 0000 0038, ... , 0000 0000 0000 0174)

      При достижении конечного значения функция завершает генерацию 

Модуль **masks** содержит функции для маскировки номера счёта и карты:

- Функция `get_mask_card_number`

Принимает номер карты и возвращает маску номера в формате XXXX XX** **** XXXX 

     Пример: 2200798045408078 - 2200 79** **** 8078

- Функция `get_mask_account`

Принимает номер счета и возвращает маску номера в формате **XXXX

     Пример: 589372269084 - **9084

Модуль **widget** содержит функции для работы с банковскими данными:

- Функция `mask_account_card`

Принимает  строку, содержащую тип и номер карты или номер счета, и возвращает замаскированный номер 
в нужном формате.

     Пример: Visa Platinum 2200798045408078 - Visa Platinum  2200 79** **** 8078
             
             Счет 589372269084 - Счет **9084

- Функция `get_date`

Принимает на вход дату в формате ГГГГ-ММ-ДДTЧЧ:ММ:СС
и возвращает дату в формате ДД.ММ.ГГГГ.

      Пример: "2000-01-01T00:0:00" - "01.01.2000"

- Функция `filter_by_statestr`

## Тестирование

Для тестирования проекта используется библиотека `pytest`. Все основные функции покрыты тестами, 
чтобы обеспечить корректность работы программы.

- **Запуск тестов**

Для запуска тестов используется команда:

`pytest tests/`



- **Покрытие тестами**

Код проекта покрыт тестами более чем на 80%, что позволяет уверенно говорить о его надежности.

- **Отчеты покрытия**

HTML-отчеты по покрытию тестами можно найти в папке `htmlcov` после выполнения команды:

`pytest --cov=`

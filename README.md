# Учебный проект по Python

## В данном проекте реализованы функции маскировки номера банковского счета и номера карты, а также сортировка банковских операций по состоянию транзакии и дате

### **Инструкция по установке:**

1. Клонируйте проект используя команду:

```
git clone git@github.com:vajskerberv/project.git
```

2. Инициализируйте виртуальное окружение:

```
python -m venv <название_окружения>
```

3. Активируйте окружение:

- macOS и Linux:

```
source venv/bin/activate
```

- Windows:

```
venv\Scripts\activate
```

4. Установите зависимости, указанные в `requirements.txt`:
```
pip install -r requirements.txt
```

### Ниже представлены примеры выполнения фунций:

Модуль **masks** содержит функции для маскировки номера счёта и карты:

- Функция **get_mask_card_number**

Принимает номер карты и возвращает маску номера в формате XXXX XX** **** XXXX 

     Пример: 2200798045408078 - 2200 79** **** 8078

- Функция **get_mask_account**

Принимает номер счета и возвращает маску номера в формате **XXXX

     Пример: 589372269084 - **9084

Модуль **widget** содержит функции для работы с банковскими данными:

- Функция **mask_account_card**

Принимает  строку, содержащую тип и номер карты или номер счета, и возвращает замаскированный номер в нужном формате.

     Пример: Visa Platinum 2200798045408078 - Visa Platinum  2200 79** **** 8078
             
             Счет 589372269084 - Счет **9084

- Функция **get_date**

Принимает на вход дату в формате ГГГГ-ММ-ДДTЧЧ:ММ:СС
и возвращает дату в формате ДД.ММ.ГГГГ.

      Пример: "2000-01-01T00:0:00" - "01.01.2000"

Модуль **processing** содержит функции сортировки банковских операций:

- Функция **filter_by_statestr**

Сортирует список операций по типу транзакции (по умолчанию - 'EXECUTED')

        Пример 

    Ввод: [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
           {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
           {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
           {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
    
    Вывод: [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
            {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
    

- Функция **sort_by_date**

Сортирует список операций по дате (по умолчанию - убывание)

        Пример 

    Ввод: [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
           {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
           {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
           {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]
         
    Вывод: [{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
            {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, 
            {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
            {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}]
